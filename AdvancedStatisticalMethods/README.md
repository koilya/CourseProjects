# S2 Coursework
In this project, we apply Bayesian Inference analysis to de-mystifying the purpose of the Antikythera mechanism. 

# Environment requirements
To ensure that the notebook runs as expected on your device, please, ensure that you have all necessary packages installed in your working environment, using:
```bash
pip install -r requirements.txt
```

# To run this project
Please, download the entire project repository (as it contains necessary data in dataverse_files folder for notebook to run), which can be done by using the following command in your terminal:
```bash
git clone <link>
```
The main file with code is S2Coursework.ipynb.

# Repository files description
- This README.md file
- report: folder containing report in PDF format
- requirements.txt: file with necessary packages information to run the project
- S2_Coursework.pdf: the task file in PDF format
- S2Coursework.ipynb: Jupyter notebook with code
- dataverse_files: folder that contains measurements in 1-Fragment_C_Hole_Measurements.csv file, images: 2-Figure 1-Composite w Hole and Section Numbers.pdf and 3-Figure-2-Engraved_Lines_with_Center.jpg, in different formats and a text file with data description: ReadMe v2.txt. It was downloaded from this reference: Thoeni, Andrew, Chris Budiselic, and Andrew Ramsey. “Replication Data for: Antikythera Mechanism Shows Evidence of Disputed Egyptian Lunar Calendar.” Harvard Dataverse, 2019. https://doi.org/10.7910/DVN/VJGLVS.
